## Technical Implementation

### Real-time Progress Updates

The runs page implements a polling mechanism for active runs:

```typescript
useEffect(() => {
  if (activeRuns.length > 0 && !progressIntervals.current.has(run.id)) {
    const interval = setInterval(async () => {
      // Fetch progress from API
      const progress = await fetchProgress(run.id)
      setProgressData(prev => new Map(prev).set(run.id, progress))
    }, 2000) // 2-second polling
    progressIntervals.current.set(run.id, interval)
  }
}, [activeRuns])
```

### Toast Deduplication

Uses `useRef` to track previous status and prevent duplicate toasts:

```typescript
const prevProgressRef = useRef<Map<string, string>>(new Map())
useEffect(() => {
  items.forEach((item) => {
    const prevStatus = prevProgressRef.current.get(item.id)
    const currentStatus = progress?.status

    if (prevStatus && prevStatus !== currentStatus) {
      // Only show toast if status actually changed
      setMsg(`Run completed successfully`)
    }
    prevProgressRef.current.set(item.id, currentStatus)
  })
}, [progressData])
```
